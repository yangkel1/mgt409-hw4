# Campus Customs front end

React + Vite + TypeScript storefront with the floating chat (Dan). See `../README.md` for full setup.

```bash
npm install
npm run dev      # http://localhost:5173 (expects the backend on http://localhost:8000)
npm run build    # type-check + production build
```

Set `VITE_API_URL` in `frontend/.env` to point at a different backend (see `.env.example`).
